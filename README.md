## Library

Axios — Promise-based HTTP client for the browser and Node.js
Docs: https://axios-http.com

## What It Does

Axios makes HTTP requests simpler than the native `fetch` API. It provides automatic JSON parsing, cleaner error handling, and supports `async`/`await` syntax out of the box.

## Why i choose axios

My portfolio project is a music streaming app. The biggest technical need was a clean, reliable way to fetch music data from an API. Axios was the right fit because it returns parsed JSON directly (no extra `.json()` step), handles errors in a try/catch block, and integrates cleanly with React's state management.

## Install
